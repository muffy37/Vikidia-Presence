## Installation

### Installer PreMid
Tout d'abord, vous devez avoir l'extension et l'application PreMid installées sur votre navigateur d'ordinateur.
👉 [Télécharger PreMid](https://premid.app/downloads)

### Configurer le mode Développeur
* Ouvrez l'extension PreMid dans votre navigateur.
* Connectez-vous à votre compte Discord.
* Allez dans les **Paramètres** et activez le mode **Développeur d'activité**.

### Télécharger la présence
Récupérez les fichiers nécessaires sur la page des releases :
👉 [Télécharger le code (v1.0.0)](https://github.com/muffy37/Vikidia-Presence/releases/tag/main)

### Importer sur PreMid
* Rendez-vous dans l'onglet **Développeur d'activité** de votre extension PreMid.
* Cliquez sur **Importer** et sélectionnez le fichier que vous venez de télécharger.
